# 📱 Social Media Impact on Life 

## 📌 Overview

Social media has become an important part of everyday life, especially among students. However, excessive social media usage may influence students' sleeping habits, daily routines, and overall lifestyle.

This Data Analytics project explores the relationship between social media usage and students' lifestyle, with a particular focus on daily usage hours, sleep duration, and sleep quality.

## 🎯Objectives

- Analyze students' social media usage patterns.
- Identify the most popular social media platforms.
- Understand daily and weekend social media usage.
- Explore the relationship between social media usage and sleep duration.
- Examine students' sleep quality.
- Identify patterns based on age, gender, and academic level.

## 📂 Dataset Information

The dataset contains the following attributes:

| Column | Description |
|---|---|
| Student_ID | Unique student identifier |
| Age | Age of the student |
| Gender | Gender of the student |
| Academic_Level | Student's academic level |
| Primary_Platform | Most-used social media platform |
| Daily_Usage_Hours | Daily social media usage |
| Weekend_Extra_Hours | Additional weekend usage |
| Device_Type | Device used by the student |
| Sleep_Duration_Hours | Daily sleep duration |
| Sleep_Quality_Score | Sleep quality rating |
